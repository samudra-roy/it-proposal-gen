# 🧠 IT Project Proposal Generator (GenAI)

A GenAI-powered tool that generates professional **IT project proposals** from a client brief or RFP document.

---

## 🚀 Overview

This project helps consultants and IT solution architects automatically create structured, business-ready project proposals using **Google Gemini 2.5 Flash** (Generative AI model).

### 💡 What it does

You give it:
- A short text brief, or
- A client RFP (coming soon: PDF upload)

It returns a full proposal with:
1. Executive Summary  
2. Scope & Deliverables  
3. Technical Architecture & Recommended Stack  
4. Timeline & Key Milestones  
5. Team & Roles  
6. High-Level Cost Estimate  
7. Risks & Mitigations  
8. Closing Statement  

---

## 🧰 Tech Stack

| Component | Technology |
|------------|-------------|
| LLM | Google Gemini 2.5 Flash |
| Backend | Python 3 |
| Web App | Streamlit |
| PDF Reader | PyPDF2 |
| PowerPoint Export | python-pptx |
| Env Management | python-dotenv |
